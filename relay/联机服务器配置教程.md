# 联机服务器配置教程（Windows / Linux）

## 文件说明

- `relay.py`：联机服务器主程序
- `admin.py`：网页后台（默认端口 7001）
- `gamemode.py`：玩法扩展框架（可自定义玩法）
- `config.json`：全部配置
- `requirements.txt`：Python 依赖

## Windows

1. 安装 Python 3.10+（勾选 “Add to PATH”）。
2. 双击 `启动联机服.bat`：自动安装依赖并同时启动联机服（7000）与后台（7001）。
3. 客户端连接地址：`你的IP:7000`；后台：`http://127.0.0.1:7001`。

## Linux

```bash
chmod +x start.sh stop.sh
./start.sh
```

systemd 方式：

```bash
sudo cp sfm-relay.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now sfm-relay
```

## 配置（config.json）

| 字段 | 说明 |
|---|---|
| `host` / `port` | 监听地址与端口（默认 0.0.0.0:7000） |
| `domain` | 对外域名（上报用） |
| `master_report` | 总服上报接口；留空则纯局域网/不参与列表 |
| `secret` | 客户端连接密钥，务必改为随机长字符串 |
| `max_online` / `max_rooms` / `room_max_players` | 在线/房间/房间人数上限 |
| `room_timeout` | 空房回收秒数 |
| `lan_only` | true 时仅允许内网 IP |
| `admin.user` / `admin.password` | 后台登录账号密码 |

修改配置后重启服务生效。
