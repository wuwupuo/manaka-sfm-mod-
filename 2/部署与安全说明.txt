============================================================
 SFM 服务器加固版 部署与安全说明
============================================================

【1. 客户端连接用的 URL】
把 public_html 里的所有内容上传到网站根目录后：

  客户端“服务器地址”只需填 你的域名（端口可留 80）。
  程序会自动尝试 https://你的域名 和 http://你的域名 下的
  /sfm_api/index.php，找到能用的那个直接连接。

  实际接口地址（玩家用的，不需要填给玩家看）：
    https://你的域名/sfm_api/index.php
  管理后台：
    https://你的域名/sfm_api/admin.php
  客户端文件保险箱：
    https://你的域名/files/
  安全配置助手（用完全部删除）：
    https://你的域名/sfm_api/setup.php?k=你的SETUP_KEY

【2. 首次部署步骤】
  a) 用 FTP 把 public_html 里全部内容覆盖上传到网站根目录
     （注意保留 .htaccess 这类隐藏文件）。
  b) phpMyAdmin 里导入 数据库建表.sql
     （之前已建过表的可跳过，但请确认有 rate_limits 表）。
  c) 打开 protected/config.php，修改：
     - DB_NAME / DB_USER / 数据库密码
     - SETUP_KEY 改成随机串（浏览器打开 setup.php 也会生成一个）
     - $rawAdminToken：先访问 setup.php 生成 bcrypt 哈希再粘回去
  d) 打开 setup.php 页面测试数据库连接，确认“管理员已配置”。
  e) 用 FTP 删除 sfm_api/setup.php。
  f) 测试：直接访问 /protected/config.php 应显示 403；
     访问 /files/ 应出现密码框。

【3. 哪些文件夹需要加密/保护】
  - protected/：最核心的机密文件夹（数据库密码、管理密码、配置、
    日志导出目录、客户端文件存储）。网址任何情况下都不能直接访问，
    已用 .htaccess 拒绝 + PHP 直连守卫双重保护。
    如果主机允许，请把它移到网站根目录上一层，最安全。
  - sfm_api/admin.php：管理后台页面，必须先登录才能使用。
  - files/：客户端文件保险箱，必须先输入管理密码才能浏览/下载。
  - sfm_api/index.php：必须保持公开，玩家连接房间列表就靠它，
    不能整目录加密（否则玩家全部连不上）。

【4. 文件保险箱怎么用】
  要私发给朋友的文件（客户端压缩包、配置模板等）用 FTP 上传到：
    protected/storage/
  朋友访问 /files/ 输入管理密码即可下载。
  管理后台点“导出完整日志”，日志也会出现在保险箱里。

【5. 安全措施（本版本已内置）】
  - protected/ 和 storage/ 双重拦截：.htaccess 拒绝 + PHP 守卫，
    直接访问任何配置文件、日志、SQL 都会 403。
  - 根目录 .htaccess 禁止目录浏览，禁止访问 .env/.git/*.sql/*.log 等。
  - 管理后台/保险箱：只有输入正确管理密码才能使用；
    没有配置密码（或还是占位符）时所有管理功能自动锁定。
  - 登录防爆破：5分钟最多5次，错误5次自动封IP 10分钟。
  - 管理员会话绑定登录IP，8小时过期，退出即销毁。
  - 所有管理操作带 CSRF 校验，浏览器/游戏客户端双通道防护。
  - 数据库全部使用预处理参数，输入全部白名单过滤，
    防 SQL 注入、XSS、路径穿越。
  - 管理密码建议 bcrypt 哈希存储，数据库密码可 AES-256-GCM 加密。
  - 日志导出到保险箱，玩家永远无法通过接口读取服务器日志。

【6. 延迟与流量优化（v1.1.2）】
  - 你的服务器只负责“握手登记”：房间列表、创建/加入、心跳、聊天。
    玩家之间的位置、动作、服装同步是双方直连（经樱花映射/frp 隧道），
    根本不经过你的网页服务器，不会吃掉你的流量。
  - 打开公共服务器页面只发 1 个合并请求（房间列表+公告+服务器时间），
    不再分开发 2-3 个请求。
  - 所有接口响应自动 gzip 压缩，省流量。
  - 清理过期数据的任务从“每次请求都做”改成“约 1/5 概率做”，
    降低国外主机的数据库压力和每次请求延迟。
  - 客户端支持 gzip 解压和 HTTP keep-alive，重复连接更快。

【7. 多语言（v1.1.2）】
  - 服务器只下发字段名（如 wrong_password、rooms_full、yes/no），
    具体翻译由客户端本地语言库完成，目前支持中文/English，
    F8 菜单可切换。
  - 服务器端管理后台的提示保持中文，不参与翻译。

【8. 强烈建议】
  a) 给域名开 HTTPS（免费可用 Let's Encrypt / 主机商自带证书），
     否则管理密码在网络上传输会被窃听。
  b) 管理密码至少 12 位，不要和数据库密码相同。
  c) 如果主机支持，把 protected 目录移动到网站根目录之外，
     例如 /home/你的账号/private/，安全等级最高。
  d) 不要把 config.php、SQL 文件、压缩包备份放在网站根目录里。

【9. 常见问题】
  - 直接访问 /protected/config.php 不是 403？
    说明你的虚拟主机没开 .htaccess 生效（AllowOverride）。
    请找主机商开启，或者把 protected 目录移到网站根目录外。
  - 提示“管理员尚未配置”？
    说明 config.php 里 $rawAdminToken 为空或仍是占位符，
    用 setup.php 生成 bcrypt 哈希后粘贴。
  - 保险箱下载提示 401？
    管理会话已过期，重新进 /files/ 输入密码即可。
