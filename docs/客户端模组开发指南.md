# 客户端模组开发指南（详细版）

> 本指南带你在 20 分钟内做出第一个可用的联机模组。每个步骤都有完整代码。

---

## 第 0 章 概念速览

| 术语 | 含义 |
|---|---|
| **模组 (Mod)** | 一个 BepInEx 插件 DLL，引用 `SFMOnline.dll`，扩展游戏玩法 |
| **前置框架 (Ext)** | `SFMOnline.dll` 内置的 `SFMOnline.Ext` 命名空间，314 个 API |
| **联机核心 (OnlineCore)** | `SFMOnline.dll` 的网络层：房间、同步、玩具控制 |
| **服务器插件** | 服务器上 `plugins/*.py`，与客户端模组通信做权威逻辑 |
| **引擎函数** | Ext 里 `[SfmExtFunction("xxx.yyy")]` 注册的，可用 `SfmExt.CallFunction` 调用 |

**模组能做什么**：改游戏状态（兴奋度/动作/传送）、全员广播玩法（remote.*）、HUD 界面、任务/NPC/区域、积分/排行/队伍/投票、与服务器插件通信。

**模组不能做什么**：改联机核心本身的网络协议（那是 OnlineCore 的事）、绕过服务器（服务器插件才是权威）。

### 2.3 Plugin.cs（入口）

```csharp
using BepInEx;
using BepInEx.Unity.IL2CPP;
using UnityEngine;

namespace MyFirstMod
{
    [BepInPlugin("com.mymod.first", "我的第一个模组", "1.0.0")]
    public class Plugin : BasePlugin
    {
        public override void Load()
        {
            // 确保前置框架已注册（后台线程，不阻塞）
            SFMOnline.Ext.SfmExt.InitNow();
            // 挂载 MonoBehaviour
            AddComponent<MainBehaviour>();
            Log.LogInfo("我的第一个模组加载成功");
        }
    }
}
```

### 2.4 MainBehaviour.cs（玩法）

```csharp
using UnityEngine;
using SFMOnline.Ext;

namespace MyFirstMod
{
    public class MainBehaviour : MonoBehaviour
    {
        void Start()
        {
            // 游戏内弹提示（右下角通知）
            SfmExtHud.Toast("模组已启动！", 4f);

            // 屏幕中央显示文字
            SfmExtHud.CreateText("welcome", "欢迎使用我的模组", new Vector2(0.5f, 0.15f));

            // 每 3 秒在日志输出当前兴奋度
            SfmExtTimer.Every(3f, () =>
            {
                float ecstasy = SfmExtScore.Get("兴奋度");
                SfmExt.Log("当前兴奋度: " + ecstasy);
            });
        }

        void Update()
        {
            // 按 F7 触发一个全员事件
            if (Input.GetKeyDown(KeyCode.F7))
            {
                SfmExtEvent.EmitNet("my_event_f7", new SfmExtValue("hello"));
            }
        }
    }
}
```

## 第 3 章 核心概念详解

### 3.1 引擎函数调用（SfmExt.CallFunction）

所有 Ext API 都有两种调用方式：

```csharp
// 方式 A：引擎函数（通用、可被图形化编程引用）
SfmExt.CallFunction("game.set_ecstasy", new SfmExtParams().Set("value", 50));

// 方式 B：C# 直调（类型安全、有智能提示）
SfmExtGame.FnSetEcstasy(new SfmExtParams().Set("value", 50), SfmExtValue.Null);
// 或静态工具类：
SfmExtScore.Set("兴奋度", 50);
```

**SfmExtParams**：参数容器，`Set(key, value)` 链式添加。value 支持 `double/int/float/bool/string/SfmExtValue`。

**SfmExtValue**：返回值容器。
```csharp
SfmExtValue v = SfmExt.CallFunction("net.get_players", new SfmExtParams());
// 列表：v["0"] 取第 0 个，v["x"] 取键 x
string firstUid = v["0"].ToString();
// 数字：v.ToFloat()，文本：v.ToString()，布尔：v.ToBool()
```

### 3.2 事件总线（SfmExtEvent）

事件是"模组内部与模组之间"的通信方式：

```csharp
// 订阅（推荐在 Start 里）
SfmExtEvent.On("game_start", v =>
{
    SfmExtHud.Toast("游戏开始！数据: " + v.ToString());
});

// 触发本地事件
SfmExtEvent.Emit("game_start", new SfmExtValue("payload"));

// 广播联机事件（房间内所有玩家模组都能收到）
SfmExtEvent.EmitNet("game_start", new SfmExtValue("payload"));
```

**事件名规范**：`小写英文_下划线`。同一事件名在所有玩家模组中含义应一致（协议约定）。

### 3.3 定时器（SfmExtTimer）

```csharp
// 延迟
SfmExtTimer.Delay(2f, () => SfmExtHud.Toast("2 秒后"));

// 循环（推荐在 Start 里注册，不要每帧重复注册）
SfmExtTimer.Every(1f, () => { /* 每秒执行 */ });

// 等待条件
SfmExtTimer.WaitUntil(() => SfmExtScore.Get("金币") >= 100, () =>
{
    SfmExtGameplay.Announce("金币达标！");
}, timeout: 30f);
```

> 注意：`Every` 会无限循环，若不再需要请用 `SfmExtTimer.Cancel(...)`（如果有）或使用条件 `WaitUntil` 自行退出。

### 3.4 消息通道（SfmExtMsg）

**发送**：
```csharp
// 广播房间（所有玩家+服务器）
SfmExtMsg.SendToRoom(new Dictionary<string, object>
{
    ["t"] = "ext_myevent",
    ["data"] = 42
});

// 发给指定玩家
SfmExtMsg.SendToPlayer("uid123", new Dictionary<string, object>
{
    ["t"] = "ext_private", ["msg"] = "你好"
});

// 发给服务器插件
SfmExtMsg.SendToServer(new Dictionary<string, object>
{
    ["t"] = "ext", ["ns"] = "myplugin", ["op"] = "do_something", ["data"] = "参数"
});
```

**接收**：
```csharp
SfmExtMsg.On("ext_myevent", (msg, fromUid) =>
{
    var data = msg.TryGetValue("data", out var d) ? d : null;
    SfmExtHud.Toast("收到消息 from=" + fromUid + " data=" + data);
});
```

> `t` 以 `ext_` 开头才会被服务器转发到全员。`fromUid` 是发送者 uid。

### 3.5 桥接（SfmExtBridge）

前置框架与联机核心之间通过委托解耦。模组一般不需要直接操作桥接，但读取状态有用：

```csharp
if (SfmExtBridge.BridgeReady) { /* 联机桥接已就绪 */ }
string myUid = SfmExtBridge.GetLocalUid?.Invoke() ?? "";
```

## 第 4 章 常用玩法模式（带完整代码）

### 4.1 积分制玩法

```csharp
// 开局：创建积分表
SfmExtScore.CreateTable("得分", 0, synced: true); // synced=true 全员同步

// 事件加分
SfmExtEvent.On("zone_enter", v =>
{
    string uid = v.ToString();
    SfmExtScore.Add("得分", 10, broadcast: true);
    SfmExtHud.Toast("进入得分区 +10！总分: " + SfmExtScore.Get("得分"));
});
```

### 4.2 全员传送（开局准备）

```csharp

    .Set("uid", "*").Set("x", 0).Set("y", 0).Set("z", 0));

```

### 4.5 HUD 完整界面

SfmExtHud.CreateText("title", "== 我的玩法 ==", new Vector2(0.5f, 0.05f), new Color(1, 0.8f, 0.2f), 24);

    SfmExt.CallFunction("remote.orgasm", new SfmExtParams().Set("uid", "*").Set("mode", 1)));

{
    SfmExtNet.FnSendChat(new SfmExtParams().Set("text", "[我的模组] " + text), SfmExtValue.Null);

### 4.8 与服务器插件通信（完整例子）

客户端发送：
```csharp
SfmExtNet.SendToPlugin("quiz", "submit", "答案B");
```

服务器插件接收（`plugins/quiz.py`）：
```python
def on_message(client, m):
    if m.get("op") == "submit":
        uid = client["uid"]
        data_set(uid + "_ans", m.get("data"))
        send_to_uid(uid, {"t": "ext_evt", "ns": "sfmext", "evt": "quiz_submitted", "data": "已收到"})
```

客户端接收：
```csharp
SfmExtEvent.On("quiz_submitted", v => SfmExtHud.Toast(v.ToString()));
```

## 第 5 章 调试技巧

| 手段 | 用法 |
|---|---|
| 日志 | `SfmExt.Log("...")` / `SfmExt.Warn(...)` / `SfmExt.Error(...)` → `BepInEx/LogOutput.log` |
| 游戏内提示 | `SfmExtHud.Toast("...")` |
| 检查函数 | `SfmExt.HasFunction("remote.action")` |
| 异常捕获 | Ext 内部所有回调都有 try/catch，但你的代码里建议 `try { } catch (Exception e) { SfmExt.Error(e.ToString()); }` |

**常见问题**：
1. **模组不加载**：检查 `BepInEx/LogOutput.log` 是否有红色错误；确认 DLL 在 plugins 目录；确认 GUID 没冲突。
2. **看不到 Ext 函数**：确认 SFMOnline.dll 在 plugins 目录且版本 ≥ 1.0.8。
3. **联机函数无效**：单人游戏时联机消息函数无操作属正常；`SfmExtBridge.BridgeReady` 为 false 表示未连接。
4. **中文乱码**：确保 .cs 文件以 UTF-8 保存。
