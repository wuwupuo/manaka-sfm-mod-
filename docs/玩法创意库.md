## 从创意到实现（5 步法）

1. **选模式**：对照《玩法设计模式》选架构（本地/房主/服务器）
2. **拆解动作**：列出玩法需要的"动作清单"（传送？加分？特效？）
3. **查 API**：在《API参考手册》找对应函数
4. **写骨架**：先做 HUD 菜单 + 事件，把玩法跑通
5. **加细节**：倒计时、特效、公告、积分
