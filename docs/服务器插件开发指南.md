# 服务器插件开发指南（详细版）

> 服务器 = 运行 `relay.py` 的中继服务器（可自建，也可用公共服）
> 插件 = `服务器目录/plugins/*.py`，服务器启动时自动加载，支持热重载
> 本文教你从零写一个完整的服务器插件，并与客户端模组联动。

---

## 第 0 章 插件是什么

服务器插件是**服务器端的玩法逻辑**，与客户端模组（DLL）配合：

```
客户端模组 DLL（每个玩家）          服务器插件 .py（一个服务器）
─────────────────────             ─────────────────────
表现层：HUD/特效/动作/传送          权威层：计分/胜负/抽奖/存档/全局状态
SfmExtMsg.SendToServer ────────▶  on_message 处理
SfmExtEvent.On("xxx")  ◀───────── send_to_uid / broadcast_room 推送
```

**为什么需要插件**：
- 防止作弊（客户端上报分数不可信，插件裁决才算数）
- 全局状态（跨房间的排行榜、全服活动）
- 服务器权威玩法（整点活动、全服公告、房间外逻辑）

---

## 第 1 章 最小插件

创建 `服务器目录/plugins/hello.py`：

```python
VERSION = "1.0"
DESC = "最简单的插件"

def on_join(client):
    """玩家进入服务器时打招呼"""
    send_to_uid(client["uid"], {"t": "ext_evt", "ns": "sfmext", "evt": "hello", "data": "欢迎来到服务器！"})
```

重启服务器（或热重载）→ 控制台输出 `[plugin] 已加载: hello v1.0 - 最简单的插件`。

## 第 2 章 插件生命周期与钩子

| 钩子 | 签名 | 触发时机 | 用途 |
|---|---|---|---|
| `on_tick` | `()` | 每 5 秒 | 定时任务（整点活动、倒计时） |
| `on_join` | `(client)` | 玩家进入 | 欢迎、初始化数据 |
| `on_leave` | `(client)` | 玩家离开 | 清理数据、播报离开 |
| `on_room_create` | `(client, room)` | 建房 | 房间初始化 |
| `on_room_destroy` | `(room)` | 房间销毁 | 房间清理 |
| `on_chat` | `(client, text)` | 聊天 | 敏感词过滤（返回 True 吞消息） |
| `on_command` | `(client, cmd, args)` | 发 `!命令` | 聊天命令系统 |
| `on_message` | `(client, m)` | 客户端 `net.send_to_plugin` | 客户端→服务器通信主入口 |
| `on_plugin_message` | `(from_name, op, data)` | 其它插件调用 | 插件间通信 |
| `on_event` | `(evt, data)` | `broadcast_event` | 插件间广播 |
| `on_unload` | `()` | 卸载/重载 | 清理定时器、保存 |

> `VERSION` 和 `DESC` 是可选模块常量，用于服务器状态展示和客户端 `net.server_mods` 检测。

## 第 3 章 API 速查（插件内可直接用）

### 3.1 发送给客户端

```python
# 给指定玩家（uid 是字符串）
send_to_uid("uid123", {"t": "ext_evt", "ns": "sfmext", "evt": "event_name", "data": "值"})

# 广播给房间所有人
broadcast_room(rid, {"t": "ext_evt", "ns": "sfmext", "evt": "event_name", "data": 42})

# 全服广播（所有房间）
broadcast_all({"t": "ext_evt", "ns": "sfmext", "evt": "server_msg", "data": "全服公告"})

# 直接对 socket 发送
send(sock, obj)
```

> 客户端模组用 `SfmExtEvent.On("event_name", cb)` 接收。
> `"t": "ext_evt"` 是标准事件推送格式，`ns` 固定 `"sfmext"`。

### 3.2 查询

```python
clients()                 # {uid: client}
rooms()                   # {rid: room}
get_client(uid)           # 单个客户端 或 None
get_room(rid)             # 单个房间 或 None
client_room(client)       # 客户端所在房间 rid（"" = 没进房）
room_players(rid)         # 房间内玩家 uid 列表
now()                     # 时间戳（秒）
```

### 3.3 数据持久化

```python
# 自动保存到服务器目录 plugin_data.json（键 = 插件名 下的子键）
data_get("player_win_uid123", 0)      # 读取，无则默认 0
data_set("player_win_uid123", 5)      # 写入
```

### 3.4 插件间通信

```python
send_to_plugin("target_plugin", "op_name", data)   # 调 target 插件 on_plugin_message
broadcast_event("my_event", data)                   # 所有插件 on_event 收到
list_plugins()                                      # 插件名列表
```

### 3.5 日志

```python
log("任何内容", 123)    # 控制台输出 [plugin:你的插件名] ...
```

## 第 4 章 数据结构

```python
# client（客户端对象）
{
    "uid": "100001",      # 玩家唯一 ID（字符串！）
    "name": "玩家名",
    "sock": <socket>,      # 不要手动操作，用 send_to_uid
    "room": "abc123",      # 所在房间 rid（"" = 未建房）
}

# room（房间对象）
{
    "rid": "abc123",
    "name": "房间名",
    "host": "100001",      # 房主 uid
    "max": 8,              # 最大人数
    "players": {"100001": client, ...},
    "password": "",        # 密码
}
```

> 注意：所有 uid 都是字符串，`get_client(str(uid))`。

## 第 5 章 完整示例：猜谜游戏

**服务器插件 `plugins/quiz.py`**：

```python
VERSION = "1.0"
DESC = "猜谜：!quiz 出题，!answer 答题"

import random

_QUESTIONS = [
    ("1+1 等于几？", "2"),
    ("SFM 是哪个引擎做的？", "unity"),
    ("我们服务器的名字？", "sfm online"),
]

def on_command(client, cmd, args):
    rid = client_room(client)
    if not rid:
        return
    if cmd == "quiz":
        q, a = random.choice(_QUESTIONS)
        data_set("current_q", a)
        data_set("current_rid", rid)
        data_set("winner", "")
        broadcast_room(rid, {"t": "ext_evt", "ns": "sfmext", "evt": "quiz_question", "data": q})
        log("出题:", q)
    elif cmd == "answer":
        if data_get("current_rid") != rid:
            send_to_uid(client["uid"], {"t": "ext_evt", "ns": "sfmext", "evt": "quiz_wrong", "data": "还没有题目"})
            return
        if data_get("winner"):
            send_to_uid(client["uid"], {"t": "ext_evt", "ns": "sfmext", "evt": "quiz_wrong", "data": "已经有人答对了"})
            return
        ans = args[0].lower() if args else ""
        if ans == data_get("current_q", "").lower():
            data_set("winner", client["uid"])
            broadcast_room(rid, {"t": "ext_evt", "ns": "sfmext", "evt": "quiz_win", "data": client["name"]})
        else:
            send_to_uid(client["uid"], {"t": "ext_evt", "ns": "sfmext", "evt": "quiz_wrong", "data": "不对哦"})

def on_tick():
    """每 5 秒：清理超过 2 分钟的题目"""
    # 简化示例：不做清理
    pass
```

**客户端配合（模组 DLL 或直接用聊天框）**：
```csharp
SfmExtEvent.On("quiz_question", v =>
{
    SfmExtHud.CreateText("quiz", "题目：" + v.ToString(), new Vector2(0.5f, 0.2f));
    SfmExtHud.Toast("聊天里输入 !answer 答案");
});
SfmExtEvent.On("quiz_win", v =>
{
    SfmExtHud.RemoveText("quiz");
    SfmExtHud.Toast("答对了！" + v);
});
```

> 纯聊天就能玩：玩家不需要装模组，直接在聊天框输入 `!quiz` / `!answer 2` 即可！`on_chat`/`on_command` 对所有人生效。

## 第 6 章 通过客户端模组增强（net.send_to_plugin）

聊天命令适合简单交互；复杂玩法（带 UI、带数据）用客户端模组发消息：

**客户端**：
```csharp
SfmExtNet.SendToPlugin("quiz", "submit", new SfmExtValue(SfmExtValue.Type.List)
{
    ["q"] = new SfmExtValue(1),
    ["a"] = new SfmExtValue("unity")
});
```

**服务器**：
```python
def on_message(client, m):
    op = m.get("op")
    if op == "submit":
        data = m.get("data") or {}
        q = data.get("q")
        a = str(data.get("a", "")).lower()
        # 判分逻辑...
        send_to_uid(client["uid"], {"t": "ext_evt", "ns": "sfmext", "evt": "quiz_result", "data": {"ok": True, "score": 10}})
```

**客户端**：
```csharp
SfmExtEvent.On("quiz_result", v =>
{
    bool ok = v["ok"].ToBool();
    SfmExtHud.Toast(ok ? "答对了 +10" : "答错了");
});
```

> `m` 结构：`{"t":"ext", "ns":"quiz", "op":"submit", "data":..., "uid":发送者uid, "name":发送者名}`
> 插件只收到 `ns` = 自己插件名的消息。

## 第 7 章 权威计分与防作弊

**黄金法则：客户端只上报"意图"，服务器裁决"结果"。**

```python
# 反例（作弊）：客户端发 "我得了 100 分"
def on_message(client, m):
    if m.get("op") == "add_score":
        score = int(m.get("data", 0))   # 玩家可以随便发大数字！
        data_set(client["uid"] + "_score", data_get(client["uid"] + "_score", 0) + score)

# 正例：客户端发 "我完成了解谜关卡"，服务器给分
def on_message(client, m):
    if m.get("op") == "complete_puzzle":
        if m.get("data") == "secret_key_1":
            # 只有服务器知道正确密钥，客户端发什么都会被裁决
            data_set(client["uid"] + "_score", data_get(client["uid"] + "_score", 0) + 10)
            send_to_uid(client["uid"], {"t": "ext_evt", "ns": "sfmext", "evt": "score_update", "data": 10})
```

## 第 8 章 定时任务（on_tick）

```python
_last = 0

def on_tick():
    global _last
    if now() - _last >= 300:  # 每 5 分钟
        _last = now()
        broadcast_all({"t": "ext_evt", "ns": "sfmext", "evt": "server_notice", "data": "整点福利！去大厅领礼包"})
```

## 第 9 章 热重载与调试

- 服务器控制台会输出所有插件的错误堆栈（`[plugin] xxx 异常: ...`）
- 修改 .py 后**重启服务器**或调用 `reload_plugin(名字)`（如果有管理接口）
- 插件代码出错不会影响服务器本身（已 try/catch）

**调试技巧**：
```python
def on_message(client, m):
    log("收到消息:", m)        # 打印完整消息，确认字段
```
