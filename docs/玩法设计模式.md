# 玩法设计模式（联机玩法架构参考）

> 同一套玩法，不同架构能做出完全不同的体验。本文给出 10 种常用设计模式，每种都有适用场景、架构图、代码骨架。

---

## 模式 1：纯客户端广播（最简单，适合测试/同乐）

所有逻辑在客户端，通过 `EmitNet` 广播事件，人人各自执行。

```
玩家A ──EmitNet("boom")──▶ 玩家B: 播放特效
```

**适用**：特效演出、同步动作、场景装饰。

```csharp
// 玩家A
SfmExtEvent.EmitNet("boom", new SfmExtValue(SfmExtValue.Type.List)
{
    ["x"] = new SfmExtValue(10), ["y"] = new SfmExtValue(0), ["z"] = new SfmExtValue(10)
});

// 全员（含 A 自己）
SfmExtEvent.On("boom", v =>
{
    SfmExtHud.Toast("爆炸于 " + v["x"] + "," + v["z"]);
});
```

**缺点**：无权威，防不了作弊；状态不一致由玩家网络延迟导致。

## 模式 2：房主权威（适合 2-8 人小游戏）

房主（host）执行逻辑，把结果广播给全员。适合：捉迷藏、答题、回合制。

```
玩家操作 ──▶ 房主裁决 ──▶ 广播结果 ──▶ 全员显示
```

```csharp
void Start()
{
    SfmExtEvent.On("player_attempt", v =>
    {
        // 只有房主处理
        if (!SfmExtRoom.Host) return;
        string uid = v.ToString();
        // 判定
        bool win = SfmExtRandom.Pick<int>(new[] { 1, 0 }) == 1;
        SfmExtEvent.EmitNet("attempt_result", new SfmExtValue(win ? uid + "win" : uid + "lose"));
    });
}
```

**判断房主**：`SfmExtRoom.Host`（直连模式房主；relay 模式房主）。

## 模式 3：服务器权威（推荐，支持防作弊/跨房）

服务器插件裁决，客户端表现。适合：竞技、全服活动、拍卖、排行榜。

```
客户端模组 → net.send_to_plugin → 插件裁决 → broadcast_room → 全员模组表现
```

见《服务器插件开发指南》第 7 章。

## 模式 4：同步字段（连续状态同步）

`sync.*` 自动以指定频率广播字段，适合血量、进度、坐标等连续值。

```csharp
// 注册（每人都有自己的）
SfmExtSync.Register("health", SfmExtValue.Type.Number, 100, hz: 5);

// 受伤
SfmExtSync.Set("health", SfmExtSync.GetFloat("health") - 10);

// 别人变化时（全员收到）
SfmExtSync.OnChanged("health", (name, v) =>
{
    SfmExtHud.SetBarValue("hpbar", v.ToFloat() / 100f);
});
```

**注意**：`sync` 字段是所有玩家共享命名空间，名字要带前缀避免冲突（如 `"modA_health"`）。谁注册谁拥有，其他人读取同名即可（不同玩家注册同名=各自独立）。

## 模式 5：积分+事件（数值玩法）

积分表做状态，事件做通知。适合：金币、RP、成就、成长系统。

```csharp
SfmExtScore.CreateTable("金币", 0, synced: true);
SfmExtScore.Add("金币", 10, broadcast: true);

// 监听变化
SfmExtEvent.On("score_changed", v =>
{
    if (v["name"].ToString() == "金币")
        SfmExtHud.Toast("金币 +" + (v["value"].ToFloat() - v["old"].ToFloat()));
});
```

## 模式 6：任务链（剧情/引导）

任务系统 + 检查点，支持进度同步。

```csharp
var t = SfmExtTaskManager.Create("story", "主线", "完成3个检查点", rpReward: 100, synced: true);
SfmExtTaskManager.AddCheckpoint(t, "c1", new Vector3(0, 0, 0), 3f);
SfmExtTaskManager.AddCheckpoint(t, "c2", new Vector3(10, 0, 10), 3f);
SfmExtTaskManager.AddCheckpoint(t, "c3", new Vector3(20, 0, 20), 3f);
t.OnComplete = _ => SfmExtGameplay.Announce("主线完成！");
SfmExtTaskManager.Start(t);
```

## 模式 7：区域触发（事件驱动关卡）

区域 + 事件：走进区域触发效果。

```csharp
var zone = SfmExtAreaManager.Create("danger", SfmExtAreaShape.Cylinder,
    new Vector3(0, 0, 0), radius: 5, height: 4);
zone.OnEnter = (uid, a) =>
{
    if (uid.Length > 0)  // 远端玩家进入
    {
        SfmExt.CallFunction("remote.vibrate", new SfmExtParams().Set("uid", uid).Set("stage", 3));
        SfmExtHud.Toast("警告：" + uid + " 进入危险区！");
    }
};
```

## 模式 8：投票/决策（民主玩法）

```csharp
var v = SfmExtVote.Start("kick_vote", "要不要开始游戏？", new[] { "开始", "再等等" }, 30f);
v.OnResult((id, winners, counts) =>
{
    if (winners.Count > 0 && winners[0] == 0)
        SfmExtEvent.EmitNet("game_start");
});
```

## 模式 9：随机点名（派对玩法）

```csharp
SfmExtTimer.Every(20f, () =>
{
    string uid = SfmExtRandom.PickRandomPlayer();
    if (uid.Length > 0)
    {
        SfmExtGameplay.Announce("被选中：" + uid + "！");
        SfmExt.CallFunction("remote.teleport", new SfmExtParams().Set("uid", uid).Set("x", 0).Set("y", 0).Set("z", 0));
        SfmExt.CallFunction("remote.orgasm", new SfmExtParams().Set("uid", uid).Set("mode", 2));
    }
});
```

## 模式 10：NPC 剧情（场景角色）

```csharp
var npc = SfmExtNpcManager.SpawnSynced("guard", new Vector3(5, 0, 5), "通行证？", sourceModel: "scene:5");
npc.OnInteract = (n, uid) =>
{
    if (SfmExtScore.Get("通行证") >= 1)
        SfmExtEvent.EmitNet("gate_open");
    else
        SfmExtHud.Toast("你没有通行证！");
};
```

## 命名规范建议

| 类型 | 规范 | 示例 |
|---|---|---|
| 事件名 | `小写_下划线`，带模组前缀 | `quiz_start`、`hide_found` |
| 积分表名 | 中文或英文，避免空格 | `金币`、`score` |
| 同步字段 | 模组前缀_字段 | `mmo_health` |
| 自定义消息 t | `ext_` 开头 | `ext_quiz` |
| 插件 ns | 插件文件名 | `quiz` |
