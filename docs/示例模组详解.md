# 示例模组详解

三个开箱即用的示例，从简单到复杂：

| 示例 | 模式 | 需要服务器插件 | 难度 |
|---|---|---|---|
| [ExampleTask](#exampletask-任务剧情) | 纯客户端 | 否 | ★ |
| [ExampleHideSeek](#examplehideseek-捉迷藏) | 房主权威 | 否 | ★★ |
| [ExampleQuiz](#examplequiz-答题游戏) | 服务器权威 | 是（quiz.py） | ★★★ |

---

## ExampleTask（任务剧情）

**玩法**：接取任务 → 走到检查点 → NPC 对话 → 完成任务得 RP。

**文件**：`examples/ExampleTask/TaskQuestBehaviour.cs`

**演示的能力**：
- 任务系统（`SfmExtTaskManager.Create`，synced 进度同步）
- 检查点（`AddCheckpoint`，自动检测玩家进入）
- NPC（`SfmExtNpcManager.SpawnSynced` 全员可见）
- 积分（`SfmExtScore.Add`）
- 事件回调（`OnCheckpointChanged` / `OnComplete`）

**编译**：复制到工程（参考 ExampleQuiz 的 csproj），编译后 DLL 放 `BepInEx/plugins/`。

**玩法流程**：
1. 打开"任务"窗口 → 接取任务
2. 走到"hall"检查点（自动检测）
3. 靠近生成的 NPC 按 F → 得 50 RP
4. 走到"garden"检查点 → 任务完成 +100 RP + 全员特效

## ExampleHideSeek（捉迷藏）

**玩法**：房主开局 → 全员传送到起点蹲下 → 房主抓人 → 抓到惩罚（高潮+传回）→ 全抓完结束。

**文件**：`examples/ExampleHideSeek/HideSeekBehaviour.cs`

**演示的能力**：
- 房主权威模式（`SfmExtRoom.Host` 判断）
- 远程玩法控制（`remote.teleport` / `remote.crouch` / `remote.orgasm` / `remote.reset`）
- 倒计时（`SfmExtGameplay.StartCountdown`）
- 玩家距离检测（`SfmExtBridge.GetGhostPosition`）
- 全员广播（`SfmExtEvent.EmitNet`）
- 公告（`SfmExtGameplay.Announce`）

**玩法流程**：
1. 房主按 F8 或点"开始游戏"
2. 全员传送到 (0,0,0) 并蹲下，30 秒倒计时
3. 房主走到某玩家 2 米内 → 广播"抓到 XX"
4. 被抓者被强制高潮并传回起点
5. 全部抓完或时间到 → 结束，全员站起复位

## ExampleQuiz（答题游戏）

**玩法**：`!quiz` 出题 → 全员聊天框 `!answer 答案` 抢答 → 服务器插件判分 → 答对者 +10 分，全员看到公告+特效。

**文件**：
- 客户端：`examples/ExampleQuiz/Mod/`（Plugin.cs 见 QuizBehaviour.cs，csproj 用 `$(SFM_GAME_DIR)` 环境变量）
- 服务器：`examples/ExampleQuiz/Plugin/quiz.py`

**演示的能力**：
- 服务器权威计分（防作弊）
- 聊天命令系统（`on_command`）
- 客户端 ↔ 服务器消息（`on_message` / `net.send_to_plugin`）
- 插件数据持久化（`data_set`）
- HUD 按钮窗口（`SfmExtHud.CreateWindow`）

**安装**：
1. 客户端：编译 Mod 工程 → `ExampleQuiz.dll` 放 `BepInEx/plugins/`
2. 服务器：`quiz.py` 放服务器 `plugins/` 目录，重启服务器
3. 游戏内：进房 → 聊天框 `!quiz` 出题 → `!answer 2` 抢答

**扩展思路**：
- 换成自定义题库（JSON 文件，`file.read` 读取）
- 加积分榜（`rank.set`）
- 答对惩罚（`remote.orgasm`）
- 连击奖励（`data_set` 记录连击数）

## 如何把示例改造成自己的模组

1. 复制示例目录，改 `AssemblyName` 和 `[BepInPlugin]` GUID
2. 改类名和玩法逻辑
3. 换 `AddComponent<你的类>()`
4. 编译 → 安装 → 测试
