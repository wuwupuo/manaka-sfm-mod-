# SFM Online——属于玩家的联机 Mod

如果你玩的是「隐秘露出 真菜香的禁忌快感」这款游戏，那么 SFM Online 就是为它量身打造的联机模组。一句话概括：装上它，你的游戏就有了账号、服务器列表、好友、聊天和房间联机，而且这一切都开源。

## 对玩家来说，它解决了什么

- 一键联机：打开游戏按 F12，就能看到服务器列表，每台服务器会显示延迟、在线人数、房间数和人数上限，点一下就能连。
- 账号体系：注册、登录、找回密码，用户 ID 从 100001 起顺延，验证码、协议同意都做齐了。
- 好友与社交：加好友、私聊、公屏聊天，管理员可以在线处理举报。
- 房内联机：创建房间、加入房间、房内聊天，动作同步。
- 自动更新：有新版会提示更新，下载后告诉你文件放在哪，手动覆盖即可。

## 开源在哪

SFM Online 最特别的地方是：联机服务器是开源的。你不只是“玩家”，也可以成为“服主”。

- 想开自己的服务器？官方开源了联机服，照着部署即可。
- 服务器后台是网页版：看在线人数、房间、聊天记录，踢人、删房、发公告，还支持中英文。
- 注意：创建服务器时，需要与官方服务器进行数据交换，这是联机体系的一部分，也是保证公平和安全的前提。

## 对服主的友好设计

- 支持强制 Mod 检测：玩家连接时自动检查指定文件或文件夹，缺了可以提示安装。
- 黑白名单、封禁、管理员权限都有。
- 总服统一管理域名，屏蔽违规服务器。
