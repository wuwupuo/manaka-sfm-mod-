# SFM Online（SFM 在线联机）

> 🌐 [English](README_EN.md) | 中文

为商业 Unity 游戏《Secret Flasher: Manaka》（隐秘露出 真菜香的禁忌快感）开发的**多人联机模组**，基于 BepInEx + IL2CPP。

本项目只做纯工程层的事情：把单机游戏接入联网（房间、聊天、玩家状态/动作同步、控制玩法、安全与运维），**不包含、不创作、不生成任何游戏内容**。反编译的 Assembly-CSharp 仅作内部技术参考，不对外分发。

---

## ✨ 功能

- **三种联机方式**：局域网 / 内网穿透 / 联机服务器（总服服务器列表）
- **房间系统**：创建房间（图形验证码）、房间列表实时刷新、房主踢人、房间设置（技能/属性加成开关）
- **玩家同步**：坐标、朝向、动作状态、髋部中心点贴地、衣服/脱衣程度、露出状态、NPC 动作与位置同步
- **控制玩法**：振动器/伸缩棒 4 档、玩具穿戴（阴蒂/乳头/塞肛/眼罩）、手铐（前/后/定时）、坐站切换、脱衣循环、排尿/强制高潮（含水流特效）、远程动作列表（全动作触发）
- **强制恢复**：HUD 按钮 / `Alt+F3`，一键清除所有控制/玩具/动作状态
- **语言**：中/英文界面切换
- **安全**：AES/HMAC 会话加密、登录图形验证码（失败后强制）、邮箱验证码前置验证码、聊天屏蔽词/限流、服务器投稿审核
- **后台**：联机服自带网页后台（中英双语），支持总览/房间/社交/公告/账号/模组/日志/设置

## 🚀 客户端使用教程

1. 安装整合包要求的 BepInEx 环境（游戏本体）。
2. 客户端**已开源**：源码见 [SFMOnline.Client/](SFMOnline.Client/)（取消加密，可直接编译）；不想自己编译可从 [client/SFMOnline_1.0.10.dll](client/SFMOnline_1.0.10.dll) 下载编译好的 DLL，重命名为 `SFMOnline.dll` 放到 `BepInEx/plugins/`。
3. 启动游戏：`F10` 联机菜单、`F12` 普通菜单、`F11` 聊天。
4. 登录后：`F10` → 总服务器列表选择服务器 → 房间页创建/加入房间；或局域网/内网穿透房间。
5. 游戏内按 `Alt+F3` 随时强制恢复所有控制状态。

## 🖥️ 联机服务器

支持 **Windows 一键启动** 与 **Linux（systemd / 脚本）**，自带网页后台。

> ⚠️ **联机服务器运行过程中必须与总服进行数据共享（master_report）**，否则将无法正常开展服务器，无论是否位于总服服务器列表中；未配置 master_report 会直接拒绝启动。

```bash
# Linux
chmod +x start.sh stop.sh
./start.sh
# 后台：http://127.0.0.1:7001
```

Windows 直接双击 `启动联机服.bat`。

配置见 [联机服务器配置教程](relay/联机服务器配置教程.md) / [Relay Server Config Guide](relay/Relay-Server-Config-EN.md)。
