# SFM Online Agreements & Notes (English)

## 1. Data-Sharing Agreement (mandatory for relay servers)

- A relay server **must share data with the master server** while running (report server name, online count, max online, room count, per-room capacity, IP/domain, etc. to `master_report`).
- **A relay without master data sharing will refuse to start**; losing master data sharing while running also prevents the server from operating normally, regardless of whether it is on the master server list.
- The master server records every relay report and uses it for listing, review, and banning.

## 3. Deployment Agreement (connecting a server)

- Deployers must keep the network stable, bandwidth sufficient, and protect player privacy.
- Server admins must follow the "Server List Submission & Review" rules: no advertising, no pay-to-enter, no in-game benefits in exchange for sponsorships, no money transactions; free-will donations without in-game benefits are allowed.
- Violating servers may be removed from the list and banned (domain/IP).
