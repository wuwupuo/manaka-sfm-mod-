# 客户端使用教程

## 安装

1. 确保游戏为《隐秘露出 真菜香的禁忌快感》整合包，且已安装 BepInEx。
2. 将编译好的 `SFMOnline.dll` 放入 `BepInEx/plugins/`。
3. 启动游戏。

## 操作

| 按键 | 功能 |
|---|---|
| F10 | 联机菜单（登录后连接服务器/创建加入房间/局域网） |
| F11 | 聊天 |
| F12 | 普通菜单（个人/设置/关于） |
| Alt+F3 | 强制恢复所有控制状态（HUD 右上角也有按钮） |
| Shift+F9 | 导出场景组件清单到 `BepInEx/SFMOnline_export.txt` |

## 联机流程

1. 在登录界面登录账号（密码登录失败一次后需先通过图形验证码；邮箱验证码需先通过图形验证码）。
2. F10 → 总服务器列表 → 选择一个联机服务器。
3. 房间页：创建房间（输入图形验证码）或加入房间；局域网/内网穿透在“局域网/内网”分区。
4. 在房间内可请求控制其他玩家（对方同意后），使用高级控制面板的所有功能。

## 常见问题

- 进游戏白屏/卡：低配机器首次加载会延迟初始化，等待几秒。
- 房间列表看不到：房间页会自动刷新，也可点“刷新房间列表”。
- 控制无效：确认对方已同意控制；仍异常时按 Alt+F3 强制恢复。
